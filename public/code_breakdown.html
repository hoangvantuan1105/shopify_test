Luồng OAuth 2.0 & Quản lý Token

Chức Năng Chính

Quản lý toàn bộ luồng đăng nhập và cấp quyền OAuth 2.0 giữa Shopify và ứng dụng. Đảm bảo xác thực đúng cửa hàng, chống tấn công giả mạo (CSRF/Timing Attack) và lưu trữ mã access_token vĩnh viễn vào bảng shops.

Các Hàm Cốt Lõi

  • redirect(Request $request): Khởi tạo URL ủy quyền kèm state nonce.
  • callback(Request $request): Nhận code, xác thực HMAC, đổi lấy permanent access token.
  • validateHmac(array $params): Tách tham số hmac và so sánh hash an toàn bằng hash_equals.

Luồng Dữ Liệu

Merchant ➔ /auth?shop=... ➔ Chuyển hướng Shopify Admin ➔ Merchant chấp thuận ➔ Shopify gọi /auth/callback ➔ Lưu Shop Model ➔ Chuyển đến /products.

Đoạn code then chốt: Xác thực chữ ký HMAC SHA-256 an toàn 
protected function validateHmac(array $params): bool
{
    if (!isset($params['hmac'])) return false;
    $hmac = $params['hmac'];

    // 1. Loại bỏ hmac và signature khỏi mảng tham số theo chuẩn Shopify
    unset($params['hmac'], $params['signature']);

    // 2. Sắp xếp các khóa tham số theo thứ tự alphabet A-Z
    ksort($params);

    // 3. Ghép chuỗi query chuẩn hóa key=value&key=value
    $queryString = http_build_query($params);

    // 4. Tính toán chữ ký SHA-256 bằng App Secret
    $calculatedHmac = hash_hmac('sha256', $queryString, config('shopify.client_secret'));

    // 5. Dùng hash_equals chống Timing Attack (an toàn tuyệt đối)
    return hash_equals($hmac, $calculatedHmac);
}
🔍 Vì sao code như vậy?

Hàm hash_equals() thực hiện so sánh chuỗi với thời gian thực thi cố định (constant time), ngăn chặn tin tặc đo lường độ trễ mạng để đoán từng ký tự của chữ ký HMAC.

Toán tử <=> đo Cosine Distance giữa 2 vector trong không gian 768 chiều. Công thức 1 - (embedding <=> query) chuyển đổi khoảng cách thành điểm số tương đồng từ 0.0 đến 1.0 (nhân 100 để hiển thị % độ khớp trên UI).

Chức Năng Chính

  • extractNextPageUrl(?string $linkHeader): Phân tích regex bóc URL rel="next".
  • cleanHtml(?string $html): Làm sạch thẻ HTML để lấy văn bản thuần cho embedding.

    ->get($url, $params);

// 2. Xử lý Rate Limit Leaky Bucket của Shopify
protected function handleRateLimit(\Illuminate\Http\Client\Response $response): void
{
    // Đọc header X-Shopify-Shop-Api-Call-Limit: "36/40"
    $callLimitHeader = $response->header('X-Shopify-Shop-Api-Call-Limit');
    if ($callLimitHeader && str_contains($callLimitHeader, '/')) {
        [$calls, $limit] = explode('/', $callLimitHeader);
        // Nếu đã dùng >= 35/40 cuộc gọi, chủ động ngủ 0.5s để thùng rò rỉ bớt!
        if ((int)$calls >= ((int)$limit - 5)) {
            usleep(500000); // 500ms
        }
    }

    // Nếu bị 429, đọc Retry-After và ngủ đúng thời gian yêu cầu
    if ($response->status() === 429) {
        $retryAfter = (float) $response->header('Retry-After', 2.0);
        usleep((int)($retryAfter * 1000000));
    }
}

Đoạn code then chốt: Streaming JSONL từng dòng chống tràn RAM 
public function streamAndProcessJsonl(string $jsonlUrl, callable $onRecord): int
{
    // Mở stream đọc nhị phân từ URL file JSONL của Shopify CDN
    $handle = fopen($jsonlUrl, 'rb');
    if ($handle === false) throw new \Exception("Không thể mở stream JSONL");

    $processedCount = 0;
    try {
        // Đọc từng dòng một - KHÔNG load toàn bộ file 500MB vào bộ nhớ RAM!
        while (($line = fgets($handle)) !== false) {
            $line = trim($line);
            if (empty($line)) continue;

            $record = json_decode($line, true);
            if (is_array($record)) {
                $onRecord($record); // Xử lý lưu DB
                $processedCount++;
            }
        }
    } finally {
        fclose($handle); // Đảm bảo luôn giải phóng con trỏ tài nguyên
    }

    return $processedCount;
}

app/Http/Middleware/VerifyShopifyWebhook.php

Xác Thực HMAC SHA-256 & Idempotency

Chức Năng Chính

Tấm khiên an ninh chặn mọi request giả mạo tới các webhook endpoint. Kiểm tra chữ ký X-Shopify-Hmac-Sha256 trên raw payload body. Đồng thời kiểm tra mã X-Shopify-Webhook-Id để loại bỏ webhook trùng lặp (Idempotency). 

// 1. Đọc raw body và chữ ký từ header
$hmacHeader = $request->header('X-Shopify-Hmac-Sha256');
$data = $request->getContent(); // Raw body chưa qua parse
$calculatedHmac = base64_encode(hash_hmac('sha256', $data, config('shopify.client_secret'), true));

if (!hash_equals($hmacHeader, $calculatedHmac)) {
    return response()->json(['error' => 'Invalid HMAC signature'], 401);
}

// 2. Chống lặp Idempotency qua Webhook ID (TTL 24h)
$webhookId = $request->header('X-Shopify-Webhook-Id');
if ($webhookId && DB::table('processed_webhooks')->where('webhook_id', $webhookId)->exists()) {
    return response()->json(['status' => 'ignored', 'message' => 'Duplicate webhook'], 200);
}
